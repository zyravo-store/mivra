# Mivra

[English](README.md) · [简体中文](README.zh-CN.md)

A clipboard, Markdown notes, bookmarks, capture and translation workspace for macOS, Windows and Linux. Find useful snippets, keep notes in view and continue from captured text. Feature availability and sign-in requirements depend on the edition and service; online providers require a network connection and may have their own charges.

## Getting started

Enable clipboard capture, copy a short public text sample, and find it in Clipboard. Search or favorite items, organize notes, tasks and bookmarks, and configure your preferred shortcuts in Settings. Feature availability depends on the operating system and the released package.

Read the [website guide](https://mivra.zyravo.store/docs). English and Chinese GitHub Wiki pages are in preparation.

## Backups and privacy

Clipboard ZIP backups and workspace JSON backups for notes, tasks and bookmarks are separate. Both are unencrypted: keep them safe and retain the originals until restored content has been checked. Configure only the permissions and third-party providers you need.

Install the published macOS package with Homebrew:

```sh
brew install --cask zyravo-store/mivra/mivra
```

Website: https://mivra.zyravo.store/ · Support: support@zyravo.store
